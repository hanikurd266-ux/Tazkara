# تذكرة في السريع — النسخة التجريبية 0.1

هذه بداية مشروع أندرويد باستخدام Kotlin وJetpack Compose. تحتوي الواجهة على قائمة مباريات تجريبية وفلاتر وزر يفتح موقع تذكرتي الرسمي.

## مهم
- أسماء المباريات والمواعيد المعروضة أمثلة فقط وليست بيانات مباشرة.
- زر التذاكر يفتح https://www.tazkarti.com/؛ لا يوجد حتى الآن ربط آلي بتوافر التذاكر أو نظام إشعارات حقيقي.
- لا يوجد تسجيل دخول أو دفع داخل التطبيق.
- قبل النشر يجب ربط بيانات موثوقة، واختبار التطبيق، وإضافة سياسة خصوصية وبيانات المتجر.

## فتح المشروع
1. نزّل Android Studio من: https://developer.android.com/studio
2. فك ضغط الملف.
3. من Android Studio اختر **Open** ثم اختر مجلد `tazkera_felsaree`.
4. وافق على تنزيل مكونات Gradle وAndroid SDK إذا طُلب منك ذلك.
5. شغّل محاكي أندرويد من Device Manager أو وصّل هاتفك مع تفعيل USB debugging.
6. اضغط زر **Run ▶**.

## إعدادات المشروع
- اسم التطبيق: تذكرة في السريع
- Package: `com.tazkera.felsaree`
- Minimum Android: 7.0 (API 24)
- Version: 0.1-demo

## الخطوات التالية
1. اختيار مصدر بيانات مباريات موثوق وشروط استخدامه.
2. ربط كل مباراة برابط التذاكر الرسمي الخاص بها، عند توفره.
3. إضافة خدمة خلفية وإشعارات Push بعد التحقق من تحديثات المصدر.
4. اختبار داخلي ثم اختبار مغلق عند انطباق متطلبات حساب Google Play.
5. تجهيز أيقونة، لقطات شاشة، سياسة خصوصية، وAndroid App Bundle.
